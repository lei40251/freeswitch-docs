## 20.26.2（发布日期：2026年5月21日） {#20262-release-date-21-may-2026}

这是包含重要安全修复和稳定性改进的重要版本，同时增加了 `reloadcert` API，可在 `mod_verto` 与 `mod_sofia` 中在线重载 TLS 证书；`mod_shout` 增加流式 TTS 格式支持（Mistral MP3 和 Inworld NDJSON/base64）；`mod_sofia` 增加 SIP 603+ 检测与透传控制；并从源码树移除了 `mod_cdr_mongodb`。建议所有用户在条件允许时升级至 v20.26.2。

* **源码压缩包：** [源码压缩包](https://fsa.freeswitch.com/downloads/freeswitch-releases/freeswitch-20.26.2.-release.tar.gz)
* **软件包：** [说明](https://freeswitch.org/confluence/display/FREESWITCH/Installation), [FSGET](https://github.com/signalwire/freeswitch/tree/master/scripts/packaging)
* **Windows 安装包：** [Windows 安装包](https://fsa.freeswitch.com/downloads/windows/x64/release/FreeSWITCH-20.26.2-Release-x64.msi)
* **Windows 音频包：** [音频包](http://files.freeswitch.org/windows/installer/x64/sounds/)
* **安装说明：** [Debian](../foundations/getting-started.mdx)
* **发行说明：** [FreeSWITCH Advantage v20.26.2 GitHub 发行说明](https://github.com/signalwire/stack/releases/tag/v20.26.2)
