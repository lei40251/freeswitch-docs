# 附录 A：默认配置目录映射 {#appendix-a-the-vanilla-configuration-map}

FreeSWITCH 随附的 `conf/vanilla/` 目录树提供一套完整、可工作的基准配置。本附录首先列出配置根目录下的所有文件和目录，然后详细列出 `autoload_configs/` 中的每个文件，让运维人员能够定位任何模块或子系统的配置，并交叉查阅本手册中对应的章节。

## 配置根目录布局 {#configuration-root-layout}

配置根目录包含顶层 XML 文件、模板文件和子目录。启动时，FreeSWITCH 通过 `freeswitch.xml` 中的 `#include` 与 `X-PRE-PROCESS` 指令，将这些内容组合成一份内存中的 XML 文档。子目录直接对应文档的五个顶层部分：`configuration`（来自 `autoload_configs/`）、`dialplan`、`chatplan`、`directory` 和 `languages`（来自 `lang/`）。`ivr_menus/` 和 `skinny_profiles/` 目录提供各自模块引用的附加配置片段。

### 顶层条目 {#top-level-entries}

| 路径 | 用途 |
|---|---|
| `freeswitch.xml` | 主配置文档；通过 `X-PRE-PROCESS cmd="include"` 指令组合全部配置部分。详见第 3 章《XML 配置系统》。 |
| `vars.xml` | 全局预处理器变量（`$${domain}`、`$${local_ip_v4}`、编解码器列表、端口号）。详见第 4 章《全局变量与核心设置》。 |
| `autoload_configs/` | 每个可加载模块或核心子系统对应一个 `*.conf.xml` 文件，映射到 `configuration` 部分。第 II～VII 部分有分散说明。 |
| `dialplan/` | XML 拨号计划上下文（`default`、`public`、`features`）及按上下文划分的包含目录。详见第 12 章《XML 拨号计划》和第 13 章《入站呼叫与 public 上下文》。 |
| `directory/` | 用户与域定义。包含 `default.xml` 和用于保存单个用户文件的 `default/` 目录。详见第 6 章《用户目录》。 |
| `sip_profiles/` | Sofia SIP Profile 定义（`internal.xml`、`external.xml`、IPv6 变体），以及网关定义的 `external/` 包含目录。详见第 7 章《Sofia SIP Profile》和第 8 章《网关与中继注册》。 |
| `ivr_menus/` | 由 `mod_dptools` 加载的 XML IVR 菜单定义（`demo_ivr.xml`、`new_demo_ivr.xml`）。详见第 21 章《IVR 菜单》。 |
| `skinny_profiles/` | 由 `mod_skinny` 加载的 SCCP（Skinny）Profile 定义（`internal.xml`）。详见第 11 章《其他端点》。 |
| `lang/` | 用于 `languages` 部分的语言与短语宏文件，按语言区域（`de`、`en`、`es`、`fr`、`he`、`pt`、`ru`、`sv`）组织。 |
| `chatplan/` | 通过 `mod_dialplan_xml` 路由即时消息的 XML Chatplan 上下文（`default.xml`）。 |
| `mime.types` | HTTP 子系统使用的 MIME 类型映射。 |
| `voicemail.tpl` | 语音信箱通知邮件的正文模板。详见第 19 章《语音信箱》。 |
| `notify-voicemail.tpl` | 未接来电（通知型）语音信箱邮件的正文模板。详见第 19 章《语音信箱》。 |
| `web-vm.tpl` | 语音信箱网页通知的 HTML 邮件模板。详见第 19 章《语音信箱》。 |
| `fur_elise.ttml` | 《致爱丽丝》的 TTML 音调流乐谱，用作保持音乐示例。 |
| `tetris.ttml` | 《俄罗斯方块》主题曲的 TTML 音调流乐谱，用作保持音乐示例。 |
| `extensions.conf` | 兼容 Asterisk 格式的 Extension 文件占位符，仅供参考。 |
| `config.FS0` | 部分打包脚本使用的备用配置根目录标记。 |
| `README_IMPORTANT.txt` | 默认配置树中附带的运维说明。详见第 1 章《简介与核心概念》。 |
