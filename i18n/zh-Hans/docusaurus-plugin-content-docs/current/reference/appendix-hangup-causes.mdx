# 附录 E：挂断原因代码表 {#appendix-e-hangup-cause-code-table}

FreeSWITCH 结束每个通道时都会记录一个挂断原因。可以在 `hangup_cause` 通道变量、`Hangup-Cause` 事件头、CDR 以及日志中查看它的名称。如果需要诊断呼叫建立期间的失败，请参阅[第 42 章：呼叫建立失败](../troubleshooting/call-setup-failures.mdx#reading-a-hangup-cause)。

127 及以下的代码来自 ITU-T Q.850。更高的代码是 FreeSWITCH 为标准未覆盖的情况添加的扩展。

SIP 列表示 `mod_sofia` 针对相应原因发送的响应码，映射来自 `mod_sofia.c` 中的 `hangup_cause_to_sip()`。星号表示未显式映射的原因：如果确实需要发送响应，则采用该函数的默认值 480。已经应答的呼叫通过 `BYE` 结束，而不是使用响应码。反方向（将收到的 SIP 响应映射为挂断原因）使用另一套映射，因此两者并不总是一一对应。
