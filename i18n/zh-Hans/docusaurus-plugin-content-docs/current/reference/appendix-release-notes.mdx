# 附录 F：发行说明 {#appendix-f-release-notes}

- **FreeSWITCH（开源版）：** 每个版本的发行说明均发布在 [GitHub](https://github.com/signalwire/freeswitch/releases)。
- **FreeSWITCH Enterprise：** 请参阅本手册中的 [FreeSWITCH Enterprise 发行说明](./release-notes-enterprise.mdx)。其中链接的 GitHub 逐版本发行说明位于 `signalwire/stack` 仓库，需要 FreeSWITCH Enterprise 访问权限。

要查看当前运行的版本，请在 `fs_cli` 中执行 `version` 命令：

```text
freeswitch@host> version
```
