# mod_xml_curl — 通过 HTTP 提供动态 XML {#mod_xml_curl--dynamic-xml-over-http}

`mod_xml_curl` 通过 HTTP 后端提供配置、用户目录及拨号计划的 XML 数据。

详细说明见 **[第 26 章：XML Curl 与 HTTAPI](../../integration/xml-curl.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。
