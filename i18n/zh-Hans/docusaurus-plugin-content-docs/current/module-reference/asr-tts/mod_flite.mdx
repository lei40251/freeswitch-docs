# mod_flite — Flite 文本转语音 {#mod_flite--flite-text-to-speech}

`mod_flite` 提供随 FreeSWITCH 附带的 Flite（Festival-lite）文本转语音引擎。可以在拨号计划中使用 `speak` 应用，或设置 `tts_engine=flite` 来选择它；附带的语音包括 `kal`、`awb`、`rms` 和 `slt`。

**另请参阅：** [mod_tts_commandline](./mod_tts_commandline.mdx)，了解如何通过外部命令执行文本转语音。
