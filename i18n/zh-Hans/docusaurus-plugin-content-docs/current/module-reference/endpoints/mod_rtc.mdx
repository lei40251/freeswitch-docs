# mod_rtc — WebRTC 传输 {#mod_rtc--webrtc-transport}

`mod_rtc` 提供 Verto 和基于 WSS 的 SIP 所共用的 WebRTC DTLS-SRTP 传输层。

详细说明见 **[第 9 章：使用 Verto 实现 WebRTC](../../users-endpoints/webrtc-verto.mdx)** 以及 **[第 10 章：基于 SIP（WSS）的 WebRTC](../../users-endpoints/webrtc-sip-wss.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。
