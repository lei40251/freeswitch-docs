本部分提供按模块组织的参考资料，涵盖那些尚未在主题章节中单独介绍的 FreeSWITCH 内置模块。每篇文档都将一个模块作为独立单元，说明其作用、加载时使用的模块名称、配置文件及参数（如果存在）、注册的拨号计划应用和 API 命令，以及读取或设置的通道变量。所有取值均已根据模块源码及随附配置进行核对。

模块按照其所属的 `src/mod/` 类别分组。基础 PBX 不要求加载这些模块；大多数为可选模块，除非文档另有说明，否则不在默认 `modules.conf.xml` 的加载集合中。

本部分还介绍两个商业模块：`mod_com_amd`（答录机检测）和 `mod_com_g729`（需许可的 G.729 编解码器）。它们按通道数收费授权，通过软件包安装，而不是从源码树编译。详见[商业模块与授权](./commercial-modules.mdx)。
