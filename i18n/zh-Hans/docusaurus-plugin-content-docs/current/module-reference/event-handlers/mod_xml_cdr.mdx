# mod_xml_cdr — XML 通话详单 {#mod_xml_cdr--xml-call-detail-records}

`mod_xml_cdr` 通过 HTTP POST 将 XML 格式的通话详单发送到指定端点。

详细说明见 **[第 27 章：通话详单](../../integration/call-detail-records.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。
