# mod_cdr_csv — CSV 通话详单 {#mod_cdr_csv--csv-call-detail-records}

`mod_cdr_csv` 根据可配置模板，将每条呼叫腿的通话详单（CDR）写入 CSV 文件。

详细说明见 **[第 27 章：通话详单](../../integration/call-detail-records.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。
