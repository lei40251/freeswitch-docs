# mod_snmp——SNMP 监控代理 {#mod_snmp-—-snmp-monitoring-agent}

`mod_snmp` 实现一个 SNMP AgentX 子代理，连接运行中的 Net-SNMP 主代理（通常是 `snmpd`），并在私有企业 OID `.1.3.6.1.4.1.27880` 下发布 FreeSWITCH 运行数据。模块附带自定义 MIB（`FREESWITCH-MIB`），定义三棵子树：身份标量、系统统计信息及活动通道表。

如果需要把 FreeSWITCH 纳入已有的 SNMP 监控基础设施，例如支持 SNMPv2c 的轮询工具、网络管理系统（NMS）或告警系统，可以使用该模块。所有暴露的对象均为只读，不支持 SNMP SET 操作。

## 加载模块 {#loading-the-module}

此模块**默认不加载**。在默认的 `autoload_configs/modules.conf.xml` 中，它以注释条目的形式出现。要启用，请取消注释或添加以下行：

```xml
<load module="mod_snmp"/>
```

编译时需要 Net-SNMP 开发库（`libsnmp-dev` / `net-snmp-devel`）。该模块不属于默认加载集合。

## 配置 {#configuration}

`mod_snmp` **不提供 `mod_snmp.conf.xml`**，也不读取自身的 FreeSWITCH XML 配置。AgentX 连接相关设置（套接字路径、主代理地址、ping 间隔）均由系统的 Net-SNMP 配置文件（`/etc/snmp/snmpd.conf`、`/etc/snmp/snmp.conf`）控制。模块将 AgentX ping 间隔硬编码为 2 秒，以防止运行线程在 `agent_check_and_process()` 中阻塞更长时间。

将 `src/mod/event_handlers/mod_snmp/FREESWITCH-MIB` 中的 `FREESWITCH-MIB` 文件放入 MIB 搜索路径，使 SNMP 管理工具能够解析对象名称。

## MIB 结构 {#mib-structure}

企业根节点为：

```
enterprises.freeswitch  ::=  { enterprises 27880 }
core                    ::=  { freeswitch 1 }
```

### identity——`.1.3.6.1.4.1.27880.1.1` {#identity-—-1361412788011}

标量对象组；所有对象均是只读 `DisplayString`。

| OID 后缀 | 对象名称 | 类型 | 说明 |
|---|---|---|---|
| `.1` | `versionString` | DisplayString | FreeSWITCH 版本字符串 |
| `.2` | `uuid` | DisplayString | FreeSWITCH 核心 UUID |

### systemStats——`.1.3.6.1.4.1.27880.1.2` {#systemstats-—-1361412788012}

标量对象组；所有对象均为只读。

| OID 后缀 | 对象名称 | 类型 | 说明 |
|---|---|---|---|
| `.1` | `uptime` | TimeTicks | 进程运行时间，以百分之一秒为单位 |
| `.2` | `sessionsSinceStartup` | Counter32 | 自进程启动以来的会话总数 |
| `.3` | `currentSessions` | Gauge32 | 当前活动会话数 |
| `.4` | `maxSessions` | Gauge32 | 已配置的会话上限 |
| `.5` | `currentCalls` | Gauge32 | 当前活动呼叫数 |
| `.6` | `sessionsPerSecond` | Gauge32 | 当前每秒会话数 |
| `.7` | `maxSessionsPerSecond` | Gauge32 | 已配置的每秒会话数上限 |
| `.8` | `peakSessionsPerSecond` | Gauge32 | 历史每秒会话数峰值 |
| `.9` | `peakSessionsPerSecondFiveMin` | Gauge32 | 最近 5 分钟内的每秒会话数峰值 |
| `.10` | `peakSessions` | Gauge32 | 历史最大并发会话数 |
| `.11` | `peakSessionsFiveMin` | Gauge32 | 最近 5 分钟内的并发会话数峰值 |

### channelList——`.1.3.6.1.4.1.27880.1.9` {#channellist-—-1361412788019}

活动通道只读表，以 `chanIndex` 为索引。缓存每 5 秒从 FreeSWITCH 核心数据库刷新一次。仅包括属于当前主机名的通道。

| OID 后缀 | 列名 | 类型 | 说明 |
|---|---|---|---|
| `.1.1` | `chanIndex` | Integer32 | 行索引 |
| `.1.2` | `chanUUID` | DisplayString | 通道 UUID |
| `.1.3` | `chanDirection` | DisplayString | 呼叫方向（`inbound` / `outbound`） |
| `.1.4` | `chanCreated` | DateAndTime | 通道创建时间戳（UTC） |
| `.1.5` | `chanName` | DisplayString | 通道名称 |
| `.1.6` | `chanState` | DisplayString | 通道状态字符串 |
| `.1.7` | `chanCIDName` | DisplayString | 主叫号码名称 |
| `.1.8` | `chanCIDNum` | DisplayString | 主叫号码 |
| `.1.9` | `chanInetAddressType` | InetAddressType | 发起方地址族（1=IPv4，2=IPv6） |
| `.1.10` | `chanInetAddress` | InetAddress | 发起方 IP 地址 |
| `.1.11` | `chanDest` | DisplayString | 目标号码 |
| `.1.12` | `chanApplication` | DisplayString | 当前执行的拨号计划应用 |
| `.1.13` | `chanAppData` | DisplayString | 应用参数数据 |
| `.1.14` | `chanDialplan` | DisplayString | 拨号计划类型 |
| `.1.15` | `chanContext` | DisplayString | 拨号计划上下文 |
| `.1.16` | `chanReadCodec` | DisplayString | 入站音频编解码器名称 |
| `.1.17` | `chanReadRate` | Gauge32 | 入站音频采样率（采样数/秒） |
| `.1.18` | `chanReadBitRate` | Gauge32 | 入站音频比特率（比特/秒） |
| `.1.19` | `chanWriteCodec` | DisplayString | 出站音频编解码器名称 |
| `.1.20` | `chanWriteRate` | Gauge32 | 出站音频采样率（采样数/秒） |
| `.1.21` | `chanWriteBitRate` | Gauge32 | 出站音频比特率（比特/秒） |

## SNMP 查询示例 {#example-snmp-queries}

从命令行轮询当前活动会话数（需要 Net-SNMP 工具及已加载的 `FREESWITCH-MIB`）：

```
snmpget -v2c -c public localhost FREESWITCH-MIB::currentSessions.0
snmpwalk -v2c -c public localhost FREESWITCH-MIB::channelList
```

不使用 MIB 文件，直接通过原始 OID 查询：

```
snmpget -v2c -c public localhost .1.3.6.1.4.1.27880.1.2.3.0
```

## 依赖项 {#dependencies}

构建 `mod_snmp` 需要 Net-SNMP（5.x 或更新版本）。编译 FreeSWITCH 时必须提供头文件和共享库 `libnetsnmp`。运行时需要启动 Net-SNMP 主代理（`snmpd`），并配置其接受 AgentX 子代理连接（默认 Unix 套接字为 `/var/agentx/master`）。Net-SNMP 不包含在 FreeSWITCH 源码树中，必须通过操作系统的软件包管理器单独安装（Debian/Ubuntu 使用 `libsnmp-dev`，RHEL/CentOS 使用 `net-snmp-devel`）。

**源码：** `src/mod/event_handlers/mod_snmp`
