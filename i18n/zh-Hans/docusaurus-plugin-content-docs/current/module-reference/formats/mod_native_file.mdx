# mod_native_file — 原生格式文件播放 {#mod_native_file--native-format-file-playback}

`mod_native_file` 无需转码即可播放原始编码格式的音频文件。

详细说明见 **[第 18 章：音频文件与流媒体源](../../media/audio-files-and-streaming.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。
