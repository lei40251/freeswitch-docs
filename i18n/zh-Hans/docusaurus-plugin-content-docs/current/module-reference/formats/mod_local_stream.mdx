# mod_local_stream — 本地音频流（保持音乐） {#mod_local_stream--local-stream-music-on-hold}

`mod_local_stream` 将指定目录中的多个文件轮换作为保持音乐（Music on Hold）的音频源进行流式播放。

详细说明见 **[第 18 章：音频文件与流媒体源](../../media/audio-files-and-streaming.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。
