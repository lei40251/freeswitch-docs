# mod_g729 — G.729 编解码器 {#mod_g729--g729-codec}

`mod_g729` 提供 G.729 窄带音频编解码器。

详细说明见 **[附录 B：编解码器参考](../../reference/appendix-codec-table.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。

For licensed G.729 encode and decode (transcoding), see the commercial [`mod_com_g729`](./mod_com_g729.mdx), which replaces this module in the load list.
