# mod_av — H.264/H.263 编解码器与音视频媒体 {#mod_av--h264h263-codecs-and-av-media}

`mod_av` 提供 H.264/H.263 视频编解码器及基于 libav 的媒体处理能力（`av.conf.xml`）。

详细说明见 **[第 16 章：编解码器与协商](../../media/codecs-and-negotiation.mdx)** 以及 **[附录 B：编解码器参考](../../reference/appendix-codec-table.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。
