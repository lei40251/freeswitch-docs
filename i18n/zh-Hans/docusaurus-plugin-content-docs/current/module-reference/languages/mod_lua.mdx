`mod_lua` 内嵌 Lua 运行时，用于拨号计划脚本、API 命令、XML 处理器和事件钩子。

详细说明见 **[第 28 章：脚本集成](../../integration/scripting.mdx)** 以及 **[第 48 章：嵌入式脚本 API](../../programming/scripting-apis.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。
