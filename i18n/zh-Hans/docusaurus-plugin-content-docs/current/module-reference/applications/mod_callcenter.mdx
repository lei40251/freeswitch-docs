# mod_callcenter — 呼叫中心（ACD） {#mod_callcenter--call-center-acd}

`mod_callcenter` 提供呼叫中心自动呼叫分配（ACD）功能，包括队列、坐席、坐席级别及呼叫路由策略。

  title="将队列作为一种呼叫方式"
  href="https://signalwire.com/docs/swml/reference/calling/enter-queue"

  linkText="查看 SWML 中的 enter_queue">

由 FreeSWITCH 团队创立的 SignalWire，在其 JSON/YAML 呼叫控制标记语言 SWML 中通过 [`enter_queue`](https://signalwire.com/docs/swml/reference/calling/enter-queue?utm_source=freeswitch-docs&utm_medium=callout&utm_campaign=same-engine&utm_content=mod_callcenter) 表示托管队列，并支持由 AI 坐席在第一层接听。

</SignalWireCallout>
