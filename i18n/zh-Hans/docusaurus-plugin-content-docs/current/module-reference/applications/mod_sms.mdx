# mod_sms — 短信与聊天消息路由 {#mod_sms--sms-and-chat-routing}

`mod_sms` 通过聊天计划（chatplan）路由文本和聊天消息。

详细说明见 **[第 12 章：XML 拨号计划](../../dialplan/xml-dialplan.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。

<SignalWireCallout
  title="包括运营商接入的消息服务"
  href="https://signalwire.com/docs/platform/messaging"
  page="mod-sms"
  linkText="查看 Messaging API">

SignalWire 的 Messaging API 支持使用你的号码收发 SMS 和 MMS，并在控制台中完成活动注册。无需聊天计划，也无需 SMPP 绑定连接。

</SignalWireCallout>
