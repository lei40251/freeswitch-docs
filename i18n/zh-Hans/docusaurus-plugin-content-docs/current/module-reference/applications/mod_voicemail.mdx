# mod_voicemail — 语音信箱 {#mod_voicemail--voicemail}

`mod_voicemail` 提供集成式语音信箱系统，包括邮箱、录音、播放菜单、MWI（消息等待指示）及电子邮件。

详细说明见 **[第 19 章：语音信箱](../../applications/voicemail.mdx)**。本页仅为模块索引条目；配置、参数及实际用法请参阅上述章节。
