# mod_conference — 电话会议 {#mod_conference--conferencing}

`mod_conference` 提供多人音频与视频会议功能。

<SignalWireCallout
  title="一次会议调用就是一种方法"
  href="https://signalwire.com/docs/swml/reference/calling/join-conference"
  page="mod_conference"
  linkText="查看 SWML 中的 join_conference">

在 SignalWire 的 JSON/YAML 呼叫控制标记语言 SWML 中，[`join_conference`](https://signalwire.com/docs/swml/reference/calling/join-conference?utm_source=freeswitch-docs&utm_medium=callout&utm_campaign=same-engine&utm_content=mod_conference) 可使用同一底层引擎，将呼叫方加入托管会议。

</SignalWireCallout>
