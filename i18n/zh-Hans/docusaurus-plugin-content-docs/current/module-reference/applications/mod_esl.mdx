# mod_esl — 远程事件套接字命令 {#mod_esl-—-remote-event-socket-commands}

`mod_esl` 是位于 `src/mod/applications/mod_esl` 的应用模块，只暴露一个 API 命令 `single_esl`，用于向远程 FreeSWITCH Event Socket Layer（ESL）服务器发送 API 请求。执行时会建立短暂的 TCP 连接、完成身份认证、发送一条 API 命令、返回应答，然后断开连接。

当一台 FreeSWITCH 上运行的拨号计划或脚本，需要调用另一台 FreeSWITCH 实例（或其他兼容 ESL 的服务器）的 API 命令，又不想维护持久的入站 ESL 连接时，可以使用该模块。对于一次性远程控制，它是比持久连接更轻量的解决方案。

## 加载模块 {#loading-the-module}

模块名为 `mod_esl`。默认 vanilla 安装的 `autoload_configs/modules.conf.xml` 中**没有**该模块，需要手动添加，才能随系统启动自动加载。

在 `autoload_configs/modules.conf.xml` 中添加：

```xml
<load module="mod_esl"/>
```

或者在运行中的 `fs_cli` 中加载：

```
load mod_esl
```

不需要特殊的构建标志。只要存在随附的 `libesl`（默认构建会编译），该模块就能使用标准 FreeSWITCH 构建系统完成编译。

## 配置：无独立 conf 文件 {#configuration-no-conf-file}

`mod_esl` 不提供 `.conf.xml` 配置文件，也没有注册配置参数。连接所需信息全部作为 `single_esl` API 命令的行内参数传入。

## API 命令 {#api-commands}

| 命令 | 用途 | 语法 |
|---------|---------|--------|
| `single_esl` | 在远程 ESL 服务器执行一次 API 调用并返回响应 | `[<user>]\|<password> <host>[:<port>] <timeout_ms> <remote_api> [<arguments>]` |

### `single_esl`

连接远程 ESL 服务器、完成认证、发送单次 `api` 命令、将响应正文返回给调用方，再断开连接。

**参数说明：**

| 字段 | 说明 | 默认值 |
|-------|-------------|---------|
| `[<user>]\|` | 可选的 ESL 用户名，后接字面量 `\|`。**竖线分隔符必须始终存在**；可以省略用户名，但不能省略竖线。 | _（空用户名）_ |
| `<password>` | ESL 密码 | `ClueCon` |
| `<host>` | 远程主机名或 IP | `127.0.0.1` |
| `<port>` | 远程 ESL 端口（通过冒号附加在主机名后） | `8021` |
| `<timeout_ms>` | 连接和接收超时，单位为毫秒 | `5000` |
| `<remote_api> [<arguments>]` | 在远程服务器执行的 API 命令及其可选参数；命令名称是必填项。 | _（必填）_ |

除 `[<user>]|` 中的用户名部分外，其余字段均为必填。分隔用户名和密码的竖线字符（`|`）**必须始终包含在参数字符串中**；如果不提供用户名，请使用 `|<password>`（用户名为空）。

**`fs_cli` 示例：**

使用默认凭据（空用户名、竖线必填）在远程 FreeSWITCH 上执行 `status`：

```
single_esl |ClueCon 192.168.1.10 5000 status
```

指定端口、但不指定用户名，执行 `status`：

```
single_esl |ClueCon 192.168.1.10:8022 5000 status
```

使用自定义密码在远程实例执行 `uuid_kill`：

```
single_esl |mypassword 192.168.1.10 3000 uuid_kill 1234abcd-5678-ef01-2345-6789abcdef01
```

指定用户名完成认证：

```
single_esl admin|mypassword 192.168.1.10 5000 show channels
```

**拨号计划示例**（通过 `api` 应用从 `<action>` 标签执行）：

```xml
<action application="set" data="remote_result=${single_esl(|ClueCon 192.168.1.10 5000 status)}"/>
```
