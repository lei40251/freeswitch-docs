前面的集成章节介绍了如何*配置*事件套接字和脚本模块。本部分将介绍如何使用它们进行*编程*：包括 FreeSWITCH 的事件模型、开发时会用到的事件目录、事件套接字的两种模式——入站模式（你的程序连接到 FreeSWITCH）和出站模式（FreeSWITCH 连接到你的程序）——以及使用 Lua 或 JavaScript 驱动呼叫的内嵌脚本 API。本部分是参考资料面向开发者的补充，重点介绍可编程接口，而非配置本身。
